================================================================
  전국 컨테이너 터미널 · 선박명 검색      (요약 / 사용설명)
================================================================

■ 이게 뭔가요
  - 선박명을 입력하면, 그 배가 "어느 항 / 어느 터미널 / 어느 선석"에
    "몇 시에 접안(입항)예정"인지 한 화면에서 바로 찾아줍니다.
  - 로그인·공인인증 필요 없음. 실시간으로 자동 갱신됩니다.


================================================================
  ★ 제일 쉬운 방법 (설치 필요 없음, 누구나)
================================================================
   ┌──────────────────────────────────────────────┐
   │   "전국컨테이너_선박검색.exe"  를 더블클릭        │
   └──────────────────────────────────────────────┘
   - 파이썬 설치 안 해도 됩니다. 그냥 이 파일 하나만 실행하면 끝.
   - 검은 창이 뜨고(첫 실행 몇 초) → 인터넷 브라우저가 자동으로 열립니다.
   - 다른 PC로 옮길 때: 이 exe 파일 하나만 복사하면 됩니다.

   ※ 만약 파란 경고창 "Windows의 PC 보호"가 뜨면 (정상입니다)
       → "추가 정보" 클릭 →  "실행" 버튼 클릭
   ※ 백신이 막으면: 이 파일을 "허용/예외"로 등록해 주세요 (오탐지입니다)


================================================================
  사용법
================================================================
  - 브라우저가 열리면 위쪽 검색창에 "선박명" 입력 → 즉시 걸러짐
  - "항" 칸(부산/평택/인천/광양/울산)으로 항별 보기
  - "터미널" 칸으로 터미널별 보기
  - 열 제목 클릭 = 정렬,  "CSV 저장" = 현재 목록을 엑셀로 저장
  - "지금 새로고침" = 즉시 최신화
  - ★ 검은 창은 켜 두세요. 닫으면 자동 갱신이 멈춥니다. (프로그램 끄기 = 검은 창 닫기)


================================================================
  지금 나오는 항 / 터미널
================================================================
  [부산] PNIT(신항2)·HJNC(신항3)·HPNT(신항4)·BNCT(신항5)·DGT(서컨)·BPT(북항 신선대·감만)
  [평택] PCTC(한진) · PNCT(동방아이포트)
  [인천] 선광·한진·E1·ICT 등 인천 전 터미널(통합)
  [광양] GWCT(서부컨테이너) · KITL(허치슨)
  [울산] UNCT(울산신항)
  ----------------------------------------------------------------
  (아직 안 나옴) 부산 PNC(신항1)  ← exe 경량판에는 빠져 있음(아래 참고)
                울산 JUCT(정일) ← 추가 작업 예정


================================================================
  PNC(신항1)까지 필요할 때만 — 고급(선택)
================================================================
  PNC는 별도 브라우저 엔진이 필요해서 exe에는 안 넣었습니다.
  PNC까지 보고 싶으면 이 폴더의 파이썬 버전을 쓰세요:
    1) 파이썬 설치 (www.python.org, 설치 시 "Add python.exe to PATH" 체크)
    2) "최초설치.bat"  더블클릭 (1번만)
    3) "실행.bat"  더블클릭
  (일반 사용자는 위 exe 방식이면 충분합니다. 이 3개 파일은 신경 안 쓰셔도 됩니다.)
