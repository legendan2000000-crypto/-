# 컨테이너 안전운임 조회 · 견적 도구 — 인수인계

설치·인터넷 없이 브라우저만으로 도는 **단일 HTML 파일** 도구.
데이터(운임표)가 파일 안에 통째로 들어 있어, `index.html` 하나만 열면 바로 동작한다.

---

## 1. 이게 뭐 하는 도구인가

항만에서 전국(또는 수도권) 목적지까지 컨테이너를 트럭으로 운송할 때의
**화물자동차 안전운임**을 조회하고, 그 내용으로 **견적서**를 만드는 도구.

**상단 탭 2개**

| 탭 | 항만 | 지역 | 거리 표기 |
|----|------|------|-----------|
| **왕복** | 14개 항만 전체 | 전국 3,480개 읍·면·동 | 거리(km) |
| **편도** | 부산신항 · 부산북항 · 광양항 (3개) | 수도권 1,213개 | 적컨 · 공컨 · 구간(km) |

> 값 비교: 같은 목적지라도 **왕복 운임 > 편도 운임** (왕복이 더 비쌈).

**기능**
- 항만 **다중 선택**(칩 클릭, 전체선택/해제)
- 도착지 **시·도 → 시·군·구 → 읍·면·동** 3단 드롭다운 (모두 **가나다순**)
- **운임 종류 선택** (표시할 컬럼을 켜고 끔)
  - 기본 3종: 안전위탁 · 사업자간(운수사업자 간) · 안전운송
  - 계산식: **위탁~사간 중간**, **사간~안전 중간**
  - **위탁 기준 N%** = 위탁 + (사간 − 위탁) × N%
  - **사간 기준 N%** = 사간 + (안전 − 사간) × N%   (N = 10~90, 1% 단위 입력)
- **CSV 다운로드** (엑셀에서 한글 안 깨짐, BOM 처리)
- **견적서(인쇄/PDF)** — 거래처명·견적일자 입력 → 인쇄 화면 → "PDF로 저장" 가능
- 모바일 대응, 라이트/다크 모드, 40FT/20FT 구분선

**운임 3종 의미**
- 안전위탁운임: 화주 → 운수사업자 지급 최저운임
- 운수사업자 간 운임: 사업자 간 하도급 운임
- 안전운송운임: 운수사업자 → 화물차주(트럭기사) 지급 운임

## 2. 폴더 구성

```
.
├─ index.html            ← ★ 완성본. 이거 하나면 실행/배포 끝 (2.8MB, 데이터 내장)
├─ README.md             ← 이 문서
├─ build.py              ← template + data → index.html 생성
├─ extract.py            ← 원본 엑셀 → data/*.json 재생성 (데이터 갱신 시에만)
├─ source/
│   └─ template.html     ← ★ 편집용 소스 (UI·로직·계산식, 데이터 없음 26KB)
└─ data/
    ├─ rates.json                 왕복 데이터 (14항만)
    ├─ rates_rt.json              편도 데이터 (3항만)
    ├─ 왕복_14항만_원본.xlsx       원본 요율표
    └─ 편도_3항만_원본.xlsx        원본 요율표
```

---

## 3. 수정하는 법 (다른 PC에서)

준비물: **Python 3** (엑셀 재추출 시 `pip install openpyxl`)

### A. UI·기능·계산식만 바꿀 때 (대부분)
1. `source/template.html` 편집
   - 계산식은 `MEASURES` 배열과 `calcVal` 함수를 보면 된다.
   - 데이터 자리표시자 `__DATA_OW__`(왕복) / `__DATA_RT__`(편도)는 건드리지 말 것.
2. `python build.py`  → `index.html` 갱신
3. `index.html` 을 브라우저로 열어 확인

> ⚠️ `index.html` 을 직접 편집하지 말 것 — 2.8MB 데이터가 섞여 있어 힘들다.
> 항상 `source/template.html` 을 고치고 `build.py` 로 다시 만든다.

### B. 운임표(데이터)가 갱신됐을 때
1. `data/왕복_14항만_원본.xlsx` / `편도_3항만_원본.xlsx` 를 새 엑셀로 교체
   (시트·열 구조가 같아야 함 — extract.py 주석 참고)
2. `python extract.py`  → `data/rates.json`, `rates_rt.json` 갱신
3. `python build.py`    → `index.html` 갱신

## 4. 배포 (Vercel)

- 저장소: GitHub `legendan2000000-crypto/-`, 루트에 `index.html`.
- Vercel이 이 저장소에 연결돼 있어, **기본 브랜치에 index.html 을 push 하면 자동 재배포**된다.
- 정적 파일이라 빌드 설정 없음(Framework: Other).

**외부에 안 열리고 로그인/403이 뜨면**: Vercel 프로젝트 →
Settings → **Deployment Protection** → **Vercel Authentication → Disabled** → Save.
