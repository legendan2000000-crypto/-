# 배차일보 웹앱 (샘플)

`26년배차일보_정리.xlsx`(2026년 5,935건)를 그대로 올려 만든 **1단계 배차일보** 샘플이다.
프레임워크 없는 단일 HTML — 나중에 Firestore + Hosting으로 옮길 때 화면·로직의 출발점.

## 실행

```
app/index.html 을 브라우저로 연다  (data.js 가 같은 폴더에 있어야 함)
```

`data.js` 는 엑셀에서 뽑은 실데이터(전화번호·금액 포함)라 **git 에 올리지 않는다**(.gitignore).
없으면 재생성:

```
python tools/extract_dispatch.py 26년배차일보_정리.xlsx    # → app/data.js
```

## 담긴 기능 (CONTEXT §8 대응)

- **배차대장** — 날짜 범위 + 통합검색, 열별 엑셀식 체크박스 필터(수출입·구분·사이즈·타입·선사·청구처), 열 머리글 정렬, 행 클릭 시 상세(주소·전화·샤시·D/O·봉인 등) 펼침. PC는 표, 폰은 카드 자동 전환.
- **지역+화주 결합 검색** — `청주SDI` 처럼 주소·화주·차량·컨번호·B/L을 한 칸에서 (공백 AND).
- **컨번호 검증** — ISO 6346 체크디짓. 통과 ✓(초록) / 불일치 ✕(빨강) / 컨테이너 형식 아님은 표시 안 함.
- **요약** — 차량·날짜·화주·청구처·선사·구분 기준 집계(건수·청구합·하불합). **현재 필터·검색 상태 그대로** 집계.
- **금액 표시 토글** — 기본 숨김(기사·현장 공유 대비). 체크 시 청구·하불 노출.
- **CSV 내보내기** — 현재 필터 결과만.
