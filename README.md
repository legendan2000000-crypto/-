# 배차일보 웹앱

배차 대장(엑셀)을 대체하는 단일 파일 웹앱. **1번(배차일보)을 메인**으로 두고,
**2번(전국 컨테이너 선박검색)을 "🚢 전국컨테이너 현황" 탭**으로 통합했습니다.

## 구성

| 파일 | 내용 |
|---|---|
| `index.html` | **배차일보 메인 앱** (단일 파일). 탭 5개. |
| `container-status/` | 전국컨테이너 현황 탭에 데이터를 공급하는 로컬 서버(`ship_search.py`)와 실행 도구. |
| `견적_안전운임조회.html` | 컨테이너 안전운임 견적 도구 (헤더의 **💰 운임견적** 링크). |
| `인수인계_컨테이너견적봇.md` | 견적봇 인수인계 문서. |

## 탭

1. **당일배차** — 최근일 하루의 배차를 시간순으로. 편집·삭제·복제·＋새 배차.
2. **＋ 입력** — 메신저 붙여넣기 / D·O·PDF·워드 드롭 → 자동 파싱 후 검토·저장.
3. **요약** — 차량·날짜·화주·청구처·선사·구분 기준 집계.
4. **조회** — 통합검색·엑셀식 필터·CSV·별칭.
5. **🚢 전국컨테이너 현황** — 전국 13개 컨테이너 터미널의 실시간 선석(접안)스케줄 검색.
   내 배차일보 선사와 매칭되는 배를 강조·필터. → 자세한 실행법은 `container-status/README.md`.

## 데이터 (개인정보)

`index.html` 에는 스키마와 **샘플 데이터**만 들어 있습니다. 실제 화주·연락처·금액은 개인정보라
저장소에 커밋하지 않습니다. 같은 폴더에 실제 **`data.js`** 를 두면 샘플을 자동으로 덮어씁니다
(`python tools/extract_dispatch.py 26년배차일보.xlsx` 로 생성 — 원본 프로젝트의 tools 참고).

## 배포

빌드가 없는 정적 앱입니다.

- **정적 호스팅(Vercel·GitHub Pages 등)**: `index.html` 을 그대로 서빙.
- **전국컨테이너 현황 탭**은 각 사용자 PC에서 `container-status/ship_search.py`(또는 exe)를
  실행해야 실시간 데이터가 뜹니다(브라우저 직접 조회 불가 — 이유는 해당 README 참고).

> ⚠ GitHub Pages는 비공개 리포라도 페이지 URL이 공개됩니다. 실데이터(`data.js`)를 올리지 마세요.
