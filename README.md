# 물류허브

물류 업무를 한 화면에서 쓰는 단일 웹앱. **큰 탭 3개**로 구성됩니다.

| 큰 탭 | 내용 |
|---|---|
| **배차일보** | 배차 대장(엑셀) 대체. 당일배차 · ＋입력 · 요약 · 조회 서브탭. |
| **내륙운송견적** | 컨테이너 안전운임(왕복/편도) 조회. (`내륙운송견적.html` 을 임베드) |
| **선명확인** | 전국 컨테이너 터미널의 실시간 선석(접안) 스케줄 검색. |

## 실행

- **가장 쉬운 방법**: 폴더의 `배차일보 실행.bat` 더블클릭
  → 브라우저에 물류허브가 열리고, (파이썬이 있으면) 선명확인용 데이터 서버도 같이 켜집니다.
- **직접 열기**: `index.html` 을 브라우저로 열어도 됩니다. (선명확인 데이터는 서버 필요 — 아래)

## 파일 구성

| 파일 | 내용 |
|---|---|
| `배차일보 실행.bat` | 실행기(더블클릭). 데이터 서버 시작 + `index.html` 열기. |
| `index.html` | 물류허브 본체(큰 탭 3개). |
| `내륙운송견적.html` | 견적 화면. '내륙운송견적' 탭에 `<iframe>` 으로 표시됨. |
| `선명확인_서버/` | 선명확인 탭에 데이터를 공급하는 로컬 서버(`ship_search.py`) 및 실행 도구. |
| `시작하기.txt` | 최소 사용 안내. |

## 선명확인 (전국 컨테이너 터미널 선석스케줄)

각 터미널 사이트는 **CORS·EUC-KR·CSRF** 때문에 브라우저에서 직접 조회가 불가능합니다.
그래서 사용자 PC에서 `선명확인_서버/ship_search.py`(또는 exe)를 실행해 전국 터미널을 대신
수집·병합하고 `http://localhost:8737/api/schedule` 로 제공하며, 선명확인 탭이 이를 30초마다
폴링합니다. 자세한 실행·연결·터미널 추가법은 `선명확인_서버/README.md` 참고.

### 배차일보 ↔ 선명확인 연동
선명확인 표에서 **선사**가 배차일보의 선사(`line`)와 매칭되는 배는 `내 선사` 배지로 강조되고,
**내 배차 선사만** 체크로 필터링됩니다.

## 데이터 (개인정보)

`index.html` 에는 스키마와 **샘플 데이터**만 들어 있습니다. 실제 화주·연락처·금액은 개인정보라
저장소에 커밋하지 않습니다. 같은 폴더에 실제 **`data.js`** 를 두면 샘플을 자동으로 덮어씁니다.

## 배포

빌드 없는 정적 앱입니다. `index.html`·`내륙운송견적.html`·`선명확인_서버/` 를 함께 서빙하세요.
선명확인 실시간 데이터는 각 사용자 PC에서 데이터 서버 실행이 필요합니다.

> ⚠ GitHub Pages는 비공개 리포라도 페이지 URL이 공개됩니다. 실데이터(`data.js`)를 올리지 마세요.
