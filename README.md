# 국양이 — 무료로 돌리기

국양로지텍 사내 물류 챗봇.
**돈 한 푼 안 들이고** 대화형 챗봇을 돌릴 수 있습니다.

|---|---|---|
| **대화** | **0원** (Gemini 무료 티어) | 필요 |
| **찾기** | 0원 | 필요 |

## 1단계 — 무료 API 키 받기 (5분)

1. https://aistudio.google.com/apikey 접속
2. **구글 계정으로 로그인** (개인 지메일이면 충분합니다)
3. **Create API key** 클릭
4. 나온 키를 복사

> ✅ **신용카드 필요 없습니다.**
> ✅ 하루 **1,000건**까지 무료. 사무소 몇 명이 쓰는 데는 넉넉합니다.
> ⚠️ 무료 티어는 **입력한 내용이 구글 학습에 쓰일 수 있습니다.**
>    그래서 아래처럼 민감한 건 아예 안 보냅니다.

---

## 민감 정보는 AI에 안 보냅니다

기본 설정(`AI_PRIVACY=strict`)에서 이렇게 나뉩니다.

| AI에게 보냄 (28개 항목) | AI에게 안 보냄 — 검색 전용 (7개 항목) |
|---|---|
| 컨테이너 제원 | **인사·급여·연차·경조휴가** |
| 샤시 규칙 | **복리후생·인사평가** |
| 도로법·과적·교량 | **선사별 자가풀기 서류** |
| 보세운송 기한·절차 | **선사코드 목록** |
| 터미널 코드 | **대아 반입전송 코드** |
| INCOTERMS·B/L·통관 | |
| 항공·부대비용·현장용어 | |

검색 전용 항목도 **[찾기] 탭에서는 전부 보입니다.** 검색은 브라우저 안에서만 돌기 때문에 **밖으로 한 글자도 안 나갑니다.**

AI에게 "연차 며칠이에요?"라고 물으면 이렇게 답합니다:
> "그건 사내 정보라 대화로는 안 알려드려요. [찾기] 탭에서 검색하시면 다 나옵니다."

## 2단계 — 내 PC에서 돌려보기

```bash
# Node.js 18 이상이 필요합니다. 없으면 nodejs.org 에서 설치.
node -v

# 이 폴더에서
npm install

# 환경변수 파일 만들기
cp .env.example .env
```

`.env` 파일을 메모장으로 열어서 두 줄만 채웁니다:

```
GEMINI_API_KEY=아까_복사한_키
ADMIN_PASSWORD=아무_암호나
```

실행:

```bash
node --env-file=.env server.js
```

브라우저에서 **http://localhost:3000** 열면 국양이가 뜹니다.

## 3단계 — 인터넷에 올려서 남들도 쓰게 (무료)

**Render** 무료 플랜을 씁니다.

1. https://render.com 가입 (깃허브 계정으로)
2. 이 폴더를 GitHub **비공개 저장소**에 올림
3. Render → **New** → **Web Service** → 그 저장소 선택
4. 설정
   - Build Command: `npm install`
   - Start Command: `node server.js`
5. **Environment** 탭에서 값 추가
   | Key | Value |
   |---|---|
   | `GEMINI_API_KEY` | 아까 그 키 |
   | `ADMIN_PASSWORD` | 정한 암호 |
   | `DATA_DIR` | `/var/data` |
   | `AI_PRIVACY` | `strict` |
6. **Disks** → **Add Disk** → Mount Path `/var/data`, 1GB
   ← **이걸 빼먹으면 배운 지식이 재배포 때 다 날아갑니다.**
7. Deploy → `https://이름.onrender.com` 링크가 나옵니다

이 링크를 카톡으로 보내면 **PC든 폰이든 열립니다.**

> ⚠️ 무료 플랜은 15분 아무도 안 쓰면 잠듭니다. 다시 열 때 **30초쯤** 걸립니다.
>    데모용으로는 문제없습니다.

---

## 첫 실행 후

1. **설정** 탭 → 관리자 암호 입력 → 잠금 해제
2. 헤더에 노란 **관리자** 배지가 뜨면 성공
3. **지식** 탭에서 새 규칙을 가르치면 전 직원 화면에 즉시 반영

직원은 **제안**만 할 수 있고, 관리자가 **반영/버림**을 고릅니다.
나중에 전면 공개하려면 **설정 → 지식 등록 권한** 스위치를 켜세요.

## 나중에 회사가 승인하면

`.env`에 이 한 줄만 추가하면 됩니다:

```
ANTHROPIC_API_KEY=sk-ant-...
AI_PRIVACY=full
```

그러면 자동으로 **Claude로 갈아타고, 민감 지식까지 전부 대화로** 답합니다.
코드는 한 줄도 안 고칩니다.
