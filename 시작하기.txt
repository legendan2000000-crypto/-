물류허브 — 시작하기
================================================

■ 이거 하나만 하세요
   이 폴더의  "배차일보 실행.bat"  을 더블클릭.
   -> 브라우저에 물류허브가 열립니다.
   -> (파이썬이 있으면) 선명확인용 '데이터 서버' 검은 창도 같이 뜹니다.

■ 큰 탭 3개
   1) 배차일보     - 당일배차 / 입력 / 요약 / 조회
   2) 내륙운송견적  - 컨테이너 안전운임(왕복/편도) 조회
   3) 선명확인     - 전국 컨테이너 터미널의 실시간 선석(접안) 스케줄 검색

■ 선명확인 탭
   - 데이터를 보려면 '데이터 서버'(검은 창)가 켜져 있어야 합니다.
   - 파이썬이 없다면: python.org 에서 설치(설치 시 "Add python.exe to PATH" 체크)
     -> 선명확인_서버\최초설치.bat 한 번 실행 -> 다시 "배차일보 실행.bat".
   - 서버 주소가 다르면 탭의 "설정(서버)" 버튼에서 바꿀 수 있습니다.

■ 폴더 구성
   배차일보 실행.bat     <- 이것만 더블클릭
   index.html            <- 물류허브 본체(탭 3개)
   내륙운송견적.html      <- 견적 화면('내륙운송견적' 탭에 임베드됨)
   선명확인_서버\         <- 선명확인 데이터 서버(ship_search.py) 등
   README.md             <- 전체 설명

■ 참고
   - 실제 배차 데이터를 넣으려면 이 폴더에 data.js 를 두면 됩니다(개인정보라 기본 미포함).
   - 선명확인은 인터넷 연결 필요(각 터미널에서 실시간 수집). 조회기간: 오늘-2 ~ 오늘+14.
